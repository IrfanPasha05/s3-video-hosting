\# AWS S3 Video Hosting



This project demonstrates how to host a video on AWS S3 and stream it using HTML.



\## Steps Performed

\- Created S3 bucket

\- Uploaded video

\- Disabled Block Public Access

\- Added bucket policy

\- Embedded video in HTML
